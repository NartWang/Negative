# Happy Family

> **让每一天的牵挂，都变成可追的温暖故事**
>
---

## 这是什么

**Happy Family** 不是又一个日记 App，也不是 emoji 心情追踪器。

它是一个 **情感翻译器**：把你忙碌、粗糙的日常（日程 + 碎片），翻译成关心你的人（父母、伴侣、朋友）能看懂、能感受到的画面和故事，并能一键寄到家庭钉钉群。

- 一句话钩子：**"让每一天的牵挂，都变成可追的温暖故事"**
- 破圈表达：**"让关心你的人能轻松、具像化地了解你。"**



---

## 核心链路（一图说清）

```
记录（全天）→ 生成日记（晚上）→ 生成画面 → 确认 → 寄给关心的人
```

用户每天只做两件事：
1. **记录** — 日程（带感受）+ 碎片速记（flomo 式）
2. **确认** — AI 生成的日记 + 画面


---

## 主要特性

| 维度 | 能力 |
|---|---|
| 输入 | 双轨道（日程 + 碎片）/ 月度打卡日历 / 多用户切换（你 / 妈妈双视角） |
| AI 日记 | 5 种情感模式（真实 / 温暖 / 幽默 / 诗意 / 自定义），段落级改写 |
| AI 绘图 | 6 种风格（治愈插画 / 水彩 / 四宫格 / 漫画 / 像素 / 自定义） |
| 周漫画 | 一周日程汇总成一张叙事漫画 |
| 双时间线 | 你与家人的同一天并排成画（沟通起点） |
| **钉钉家书** | 一键寄日记 / 漫画到家庭群，列表卡片显示「已寄出」角标 |
| 视觉打磨 | 开屏 Splash / Tab cross-fade / 温度计 shimmer |
